# Level VIII scroll recipes — source data

Transcribed verbatim from <https://asheron.fandom.com/wiki/Spell_Research>,
"Known Formulas" and "Known Failures", on 2026-11-01. This is the grammar of
the system; `data/scroll-tables.tsv` is its expansion — every concrete scroll
from the wiki's per-school scroll tables — and `src/formulas.rs` (generated by
`scripts/gen_formulas.py`) is the plugin's recipe table: the expansion, kept
to the spells this server has. The client's spell table names the components
consumed when **learning** a spell (taper, herb, powder, talisman), not the
quill, ink and glyph that **craft** its scroll. That mapping is server-side,
and this is the community's record of it.

The table is a grammar rather than a list. Each row combines one of each:

| Part | Role in the result |
|---|---|
| **Quill** | who it helps: `Introspection` self, `Benevolence` other, `Infliction` against, `Extraction` drain |
| **Ink** | how it travels: `Formation` self, `Conveyance` other, `Objectification` item, `Nullification` dispel, and the five projectile inks |
| **Glyph** | what it is about: a skill, an element, a vitals type, a weapon, an armour type |

`(...)` marks a family: the row stands for one spell per glyph in that family.

Uncraftable combinations are listed under Known Failures; the per-school
scroll tables already leave them out, so the generated recipe table contains
only combinations that make a scroll.

> Note the wiki's own caveat, carried here because it is load-bearing:
> *"Currently it is impossible to craft Creature Other Buffs, Life Other Buffs,
> Imperil, Self Debuffs."*

## Known Formulas

```
INFUSED QUILL + INK + GLYPH = SCROLL

Introspection + Formation + (Skill)   = Creature Skill Buff
Infliction    + Conveyance + (Skill)  = Creature Skill Debuff

Introspection + Formation + (Element) = Life Protection (%68)
Infliction    + Conveyance + (Element) = Life Vuln (%210)
Introspection + Formation + (Armor)   = Armor (+250 Natural)

Introspection + Formation + (Health)  = Heal Self
Benevolence   + Conveyance + (Health) = Heal Other
Infliction    + Conveyance + (Health) = Harm Other
Extraction    + Conveyance + (Health) = Drain Health (Drains 60% of target's Health)

Introspection + Formation + (Stamina) = Revitalize Self
Benevolence   + Conveyance + (Stamina) = Revitalize Other
Infliction    + Conveyance + (Stamina) = Enfeeble Other (Drains 50-100 Stamina)
Extraction    + Conveyance + (Stamina) = Drain Stamina (Drains 60% of target's Stamina)

Infliction    + Conveyance + (Mana)   = Mana Drain Other (Drains 48-90pts of Mana)
Extraction    + Conveyance + (Mana)   = Drain Mana Other (Drains 60% of target's Mana)

Introspection + Formation + (Health/Stam/Mana Regeneration Glyph) = Health/Stam/Mana Regeneration increased 145%
Infliction    + Conveyance + (Health/Stam/Mana Regeneration Glyph) = Health/Stam/Mana Regeneration reduced 75%

Extraction + Nullilfication + Damage  = Weakening Curse

Benevolence   + Objectification + (Armor) = Impenetrability (+240 AL)
Infliction    + Objectification + (Armor) = Brittlemail (-300 AL)
Benevolence   + Objectification + (Element) = Item Bane
Infliction    + Objectification + (Element) = Item Lure (Opposite of Bane)
Introspection + Objectification + Mana Conv = Hermetic Link Self (80%)
Benevolence   + Objectification + Mana Conv = Hermetic Link Other (80% bonus)
Infliction    + Objectification + Mana Conv = Hermetic Void (80% penalty)
Introspection + Objectification + Focus     = Spirit Drinker Self (7% bonus)
Benevolence   + Objectification + Focus     = Spirit Drinker Other (7% bonus)
Infliction    + Objectification + Focus     = Spirit Loather (7% penalty)
Introspection + Objectification + Quickness = Swift Killer Self
Benevolence   + Objectification + Quickness = Swift Killer Other
Infliction    + Objectification + Quickness = Leaden Weapon
Introspection + Objectification + Coord     = Heartseeker Self (+20% Attack)
Benevolence   + Objectification + Coord     = Heartseeker Other (+20% Attack)
Infliction    + Objectification + Coord     = Turn Blade (-20% Attack)
Introspection + Objectification + Melee Def = Defender Self (+17% Defense)
Benevolence   + Objectification + Melee Def = Defender Other (+17% Defense)
Infliction    + Objectification + Melee Def = Lure Blade (-20% Defense)
Introspection + Objectification + Strength  = Blood Drinker Self (+22 Damage)
Benevolence   + Objectification + Strength  = Blood Drinker Other (+22 Damage)
Infliction    + Objectification + Strength  = Blood Loather (-24 Damage)
Benevolence   + Objectification + Lockpick  = Strength Lock
Infliction    + Objectification + Lockpick  = Weaken Lock

Infliction + Alacritous + (Element) = War Streak
Infliction + Direction  + (Element) = War Bolt
Infliction + Parabolic  + (Element) = War Arc
Infliction + Partition  + (Element) = War Blast
Infliction + Separation + (Element) = War Volley

Introspection + Nullification + Life Enchantment Glyph     = Nullify Life Magic Self
Benevolence   + Nullification + Life Enchantment Glyph     = Nullify Life Magic Other
Introspection + Nullification + Creature Enchantment Glyph = Nullify Creature Magic Self
Benevolence   + Nullification + Creature Enchantment Glyph = Nullify Creature Magic Other
Introspection + Nullification + Item Enchantment Glyph     = Nullify Item Magic
```

`Nullilfication` above is the wiki's own spelling; the ink is **Nullification**.

## Casting difficulty, for reference

Not a crafting gate — level VIII crafting has no skill check. This is the
chance the finished spell lands when cast, at 400 buffed magic skill = 50%.

```
400 - 50%   410 - 67%   420 - 80%   430 - 89%   440 - 94%
405 - 57%   415 - 74%   425 - 85%   435 - 92%
```
